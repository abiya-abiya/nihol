## 5. Competitor scan

| Product | What it is | Why Nihol is different |
|---|---|---|
| **Khan Academy / Khanmigo** | strong content + GPT tutor; paid for families (US billing), free teacher tools in English only ([khanmigo.ai](https://www.khanmigo.ai/)) | no Uzbek, not tied to the Uzbek curriculum; LLM-first, so diagnosis is not deterministic |
| **Eduten** (Finland) | adaptive maths platform; UNICEF-backed pilot in 17 Uzbek schools, grade 5 ([UNICEF](https://www.unicef.org/innovation/media/24166/file/Uzbekistan%20Eduten%20Piloting%20Imp)) | practice + gamification; does not trace a wrong answer to its root prerequisite; no generative tutor in Uzbek. It shows the Ministry already buys this category — a validation, not a threat |
| **Duolingo Math** | gamified drills | drills, no diagnosis, no teacher loop, no Uzbek |
| **ChatGPT / generic chatbots** | answers anything | gives the answer, not the cause; can be wrong in maths and Uzbek; no class view |
| Local (Mohirdev, exam-prep apps, tutoring centres) | IT courses / university entrance prep | none target grade 5–6 root-cause diagnosis |

Our four differentiators, in one line each:
1. **Root cause** — graph + BKT find *why* (EKUK), not *where* (adding fractions).
2. **Uzbek-first** — content, terminology and AI explanations in correct Uzbek Latin.
3. **Teacher loop** — live class heatmap, groups by shared root gap, printable worksheet in one click.
4. **Works offline** — diagnosis runs in the browser; AI has prepared fallbacks.
